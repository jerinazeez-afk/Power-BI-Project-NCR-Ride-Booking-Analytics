# Power-BI-Project-NCR-Ride-Booking-Analytics

Developed an interactive Power BI dashboard to analyse 150K ride bookings in 2024. Evaluated booking trends, cancellation patterns, payment preferences, vehicle performance, and customer ratings to identify operational challenges and generate actionable insights for data-driven decision-making.

# NCR Ride Booking Analytics Dashboard | Power BI

## 1. Overview
This project analyses ride-booking data using Microsoft Power BI to uncover operational trends and business insights. It focuses on booking performance, cancellations, payment preferences, vehicle utilisation, and customer satisfaction to support data-driven decision-making.

## 2. Dataset
The project analyzes approximately **150,000 ride bookings from 2024**, covering:
- Booking status and booking value
- Payment methods
- Vehicle types and ride distance
- Customer and driver cancellations
- Customer and driver ratings

## 3. Tools & Technologies
- **Microsoft Power BI** – Dashboard development and visualization

## 4. Project Workflow
1. Reviewed the ride-booking dataset and identified key business metrics.
2. Analysed booking statuses, payment methods, vehicle types, and cancellation reasons.
3. Created visualisations to identify trends and performance patterns.
4. Developed an interactive dashboard to present key metrics and insights.
5. Derived business recommendations to improve operational efficiency.

## 5. Dashboard Features
- **Booking Overview:** Total bookings and booking status distribution.
- **Booking Trends:** Daily booking-value fluctuations throughout 2024.
- **Payment Analysis:** Comparison of booking value across payment methods.
- **Cancellation Analysis:** Customer and driver cancellation patterns.
- **Vehicle Performance:** Ride distance across vehicle categories.
- **Customer Experience:** Customer and driver rating analysis.

## 6. Key Results
- Analyzed approximately **150K bookings** across 2024.
- Identified a **62% ride completion rate**.
- Found driver cancellations accounted for **18% of total bookings**.
- Identified UPI as the leading payment method by booking value.
- Highlighted cancellation reduction and better driver allocation as key improvement opportunities.

## 7. Business Recommendations
- Reduce customer and driver cancellations.
- Optimise driver allocation during peak-demand periods.
- Improve service quality using customer feedback and ratings.
- Monitor booking trends to support demand forecasting.
- Optimise payment experiences based on customer preferences.

## 8. How to Run
1. Clone or download this repository.
2. Install Microsoft Power BI Desktop.
3. Download the `.pbix` dashboard file from the repository.
4. Open the file using Power BI Desktop.
5. If the dataset is provided separately, update the data source path as required.
6. Refresh the data and explore the dashboard visuals and filters.
